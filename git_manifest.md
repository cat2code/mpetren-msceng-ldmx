# Explanation of the different branches

## Branches on github

* 5models_cosmos_03_06: contains a version that is compatible with running stuff on the compute cluster cosmos that is using bash and linux
* 5models: formalizing the mldmx/ directory for my master thesis designing the codebase and framework to support and sustain 5 models: 2 transformer full self attention with ecal and tpad input and one with only ecal input, 2 GNN gravnetconv based models with ecal and tpad input and one with only ecal input and lastly 1 experimental mlpf-inspired model multitask. This was developed on mac os based system.
* main: front facing branch for the public repo
* win: windows based branch but it is getting outdated it was made before the 5models
* mac: branch for sustaining the mac based workflow but this is outdated definitely.
